1.1How the web works

Websites are stored on a server. When you type a domain name, the browser (client) sends a request over HTTP(S), and the server returns HTML, CSS, and JavaScript for the browser to display.

  1. 💻 Client The browser sends a request
  2. 🌐 Domain Points to the server hosting the site
  3. 🔒 HTTP(S) Protocol that transfers the data
  4. 🗄️ Server Receives the request, sends data back
  5. 📊 Database Data retrieved with SQL

1.2Key terms

Concept Meaning Example
Client The browser or application that sends requests and displays web pages Chrome, Edge, Safari
Server The device or program in a network that waits for incoming requests and sends back data. It can be an in-house server, a rented server, or a cloud server in a data center Websites are stored on servers
Hosting The storage area where a website's content is placed A folder holding index.html, styles.css
Web hosting A service provider with the technology needed for a website to be viewed on the internet Hosting or cloud providers
Domain name Points to a website hosted on a server example.com
HTTP(S) Hypertext Transfer Protocol (Secure): how the browser and server communicate and transfer data https://example.com

1.4Command Line

A text-based interface for typing commands and interacting with the operating system. You type commands in the Terminal; the $ shell prompt shows the terminal is ready.

Filesystem: a tree structure

/                 ← root directory
└── blog/         ← parent of 2014/ and 2015/
    ├── 2014/     ← child directory
    └── 2015/     ← working directory after "cd 2015"
        └── jan/
            └── memory/
  • Root directory: the top folder, parent of all other folders and files.
  • Parent directory: a folder that contains child folders or files.
  • Child directory: a folder inside another folder.
  • Working directory: the folder you are currently working in.

Sample terminal session

Terminal 

$ pwd
/home/ccuser/workspace/blog
$ ls
2014  2015  hardware.txt
$ cd 2015
$ mkdir media
$ touch keyboard.txt
$ ls
keyboard.txt  media
$ cd ../2014
Command Purpose Example
ls List: shows files and folders in the working directory $ ls → 2014 2015 hardware.txt
pwd Print Working Directory: shows the path of the current folder /home/ccuser/workspace/blog
cd Change Directory: moves to another folder $ cd 2015
cd .. Moves up to the parent folder blog/2015 → blog/
cd ../.. Moves up two levels 2015/jan/memory/ → 2015/
cd ../2014 Moves up one level, then into a sibling folder blog/2015/ → blog/2014/
mkdir Make Directory: creates a new folder $ mkdir media
touch Creates a new empty file $ touch keyboard.txt
Tab Autocompletes a file or folder name cd Doc + Tab → cd Documents/
↑ / ↓ Browses command history: ↑ for older commands, ↓ for newer ones Press ↑ to recall the previous command
clear Clears the Terminal screen (does not delete or undo commands) $ clear

Selector Purpose Example
Type Selects all elements with that tag name p { color: green; }
Universal * Selects every element on the page * { font-family: Verdana; }
Class . Selects by class; one element can have several classes <p class="green bold"> → .green {} .bold {}
ID # Selects one unique element by ID #large-title { }
Attribute [ ] Selects by attribute or attribute value [href] { }, img[src*='winter'] { }
Pseudo-class : Selects an element in a specific state p:hover { }, input:focus { }
Chaining The element must match every condition h1.special { color: red; }
Descendant (space) Elements nested inside another element .main-list li { color: red; }
Multiple , Applies the same CSS to several selectors h1, .menu { font-family: Georgia; }
Specificity Decides which rule wins when several apply. Adding tags, classes, or IDs to a selector raises its specificity .main p beats p

3.5Typography: font

Serif

Aa

Small strokes at the ends of letters: Georgia, Times New Roman

Sans-serif

Aa

No small strokes at the ends of letters: Arial, Helvetica

Concept Purpose Example
font-family Sets the font of an element h1 { font-family: Arial; }
Multi-word values Font names with several words go in quotes font-family: 'Times New Roman';
Web safe fonts Common fonts that display reliably across operating systems and browsers Arial, Georgia, Times New Roman
Fallback fonts Backup fonts used when the preferred font is unavailable font-family: Caslon, Georgia;
Font stack A list of fonts in priority order, left → right Caslon, Georgia, 'Times New Roman', serif
<link> Connects an online font; placed in <head> <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@100&display=swap" rel="stylesheet">
@font-face Uses a downloaded font file directly in CSS instead of <link> See the code below
Format order Preferred format order WOFF2 → WOFF → TTF 
/* 1. Declare the font */
@font-face {
  font-family: 'MyFont';                                  /* name the font */
  src: url('fonts/Roboto.woff2') format('woff2'),         /* path + format */
       url('fonts/Roboto.woff') format('woff'),
       url('fonts/Roboto.ttf') format('truetype');
}

/* 2. Use the declared font, with a fallback */
p {
  font-family: 'MyFont', sans-serif;
}
