03

Text Styles

Standard typography rules for common HTML page elements.

H1: Main Page Heading

  • Font-family: Arial, Helvetica, sans-serif
  • Font-size: 40px
  • Font-weight: 700
  • Letter-spacing: 1px
  • Text-transform: uppercase

H2: Section Heading

  • Font-family: Georgia, serif
  • Font-size: 30px
  • Font-weight: 700
  • Letter-spacing: 0.5px

H3: Component Heading

  • Font-family: Arial, Helvetica, sans-serif
  • Font-size: 20px
  • Font-weight: 700
  • Word-spacing: 2px

P: This is an example of paragraph text. Paragraphs use a comfortable line height to make longer content easier to read.

  • Font-family: Arial, Helvetica, sans-serif
  • Font-size: 16px
  • Font-weight: 400
  • Line-height: 1.7
